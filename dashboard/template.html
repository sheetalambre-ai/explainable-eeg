In one paragraph

Participants read words in Arabic, then Hindi, while 14 EEG channels were recorded. The recording is cut into 4-second windows. Each window is described by its frequency content (140 band-power numbers) and how channels move together (455 coherence numbers). A classifier learns each person from one script only and must then name them from the other script. Everything that is learned (scaling, ICA, hyperparameters) uses the training script only.

Three evaluation units, never mixed
4 sone window
32 s8 windows combined
Blockall held-out windows → reported accuracy
Input file format (live demo)

CSV, one row per 4-s window, with 140 columns named like FP1_delta_log / FP1_delta_rel. Extra columns are ignored. An optional true_participant column enables the correct/incorrect check. Rows with missing values are skipped.

Honest caveats

Both scripts were recorded in one session with Arabic always first, so this shows cross-task stability within a session, not across days. Group, sex and recording date are partly confounded. Rebuild this page with python scripts/13_export_dashboard.py. Data: Aldhaheri et al., Mendeley 7cdyp2r5cz.
