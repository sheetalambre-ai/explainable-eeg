## Preserved inputs and outputs

- Original scripts, saved results, logs, and cached windows are preserved. The original manuscript draft is `paper/main_original_draft.tex`; `paper/main.tex` is now the corrected six-section manuscript.
- Corrected code is `src/corrected_experiments.py`; dataset provenance is generated by `scripts/11_dataset_audit.py`.

- The current local dataset files match the included raw ZIP by CRC32 and byte count; see `dataset_manifest.csv` and `DATASET_PROVENANCE.md`.

## Environment

- Python 3.10.10 was available during the experiment run.
- Installed modules used by the analysis: MNE, NumPy, pandas, SciPy, scikit-learn, PyTorch, and Matplotlib.
- MNE 1.12.1 was confirmed during the runtime check. The script sets `_MNE_FAKE_HOME_DIR` and `NUMBA_CACHE_DIR` to workspace folders before importing MNE; without this on the managed Windows setup, MNE attempts to open an inaccessible user-profile config and hangs.
- CUDA was available on an NVIDIA GeForce RTX 3050 Laptop GPU (6 GB), but the corrected main comparison is classical ML and does not depend on CUDA.
- No local `pdflatex`, `xelatex`, `latexmk`, or `tectonic` command was found during final inspection; the LaTeX source has not been compiled or page-count verified.

## Commands

```powershell
python scripts/11_dataset_audit.py
python -m src.corrected_experiments
python scripts/12_reviewer_response_analysis.py
```

The corrected scripts use fixed seed 42, save feature-cache arrays with preprocessing/version metadata, save ICA leakage-audit rows by subject, and produce subject-level bootstrap, group-stratified, paired-comparison, duration, and confusion outputs. Historical full-session ICA features are re-evaluated with enrollment-only classifier tuning only as a test-distribution-exposure diagnostic.

## Interpretation limits

- The correct inferential unit is the participant, not the 4-s window.
- Same-session cross-block performance does not demonstrate cross-session persistence.
- Test language and recording time/order are coupled in the available data.
- Re-running the code reproduces the analysis of this archive, not a resolution of the public Mendeley 296/300 metadata discrepancy.
